# localhost.ge — Local Host LLC

New website for **Local Host**, inbound tour operator in Tbilisi for Georgia, Armenia and Azerbaijan: a one-page site in five languages (EN, KA, PL, IT, DE) with AI features — trip designer with voice and live route map, photo match, agency proposal builder, policy Q&A with citations, staff inquiry triage, and an MCP connector for travel agencies' AI assistants.

Built with Astro on Vercel; AI by Claude (Anthropic). Runs in demo mode until an API key is set.

```bash
npm install
npm run dev
```
